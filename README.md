# Calculadora Python

Calculadora simples feita em Python — primeiro projeto da minha jornada como programador.

## Funcionalidades
- Somar
- Subtrair
- Multiplicar
- Dividir (com proteção contra divisão por zero)

## Como usar
1. Abre o terminal
2. Corre o comando: `python calculadora.py`
3. Escolhe a operação e introduz os números

## Tecnologias
- Python 3
